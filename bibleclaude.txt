WHAT THIS IS
------------
Every Bible translation LumenLive can host and ship in a COMMERCIAL product.
NonCommercial (CC *-NC-*) texts and titles we could not license-verify have
been REMOVED - what remains is cleared for commercial redistribution, subject
to the light attribution duties noted per entry. Paid editions (NIV, ESV, ...)
were never in scope; they stay BYO-import only in the app.

This file is my own analysis/notes, not HelloAO documentation. Scratch/planning
(untracked). Regenerate from the sources under DATA SOURCES.

HEADLINE NUMBERS
----------------
  Commercial-safe titles : 502   (340 languages)
     Public Domain [PD]  : 99
     CC permissive [OK]  : 403   (CC BY / BY-SA / BY-ND)
  Recommended (must ship): 22   (section 1)
  Nice to have           : 480   (section 2, download on demand)

================================================================================
  SHOULD YOU LIST ALL 502 IN THE STORE?  -> NO.
================================================================================
Featuring 500+ versions (mostly minority-language New-Testament-only texts)
would make the version picker unusable. Recommended model:

  - SHIP / FEATURE the Recommended set (section 1). These are the 'featured'
    store cards; KJV stays bundled offline, the rest are one-click installs.
  - Offer Nice-to-have (section 2) as a browseable, download-on-demand catalog
    (search/filter by language) - present but not featured. Nothing is lost;
    it's just not shoved in front of every user.

This matches the store card's existing `featured` flag (bible-store-card.tsx).

OBLIGATIONS on the safe set (real, not blocking - we display verbatim):
  CC BY -> keep a credit line;  CC BY-SA -> credit (+share-alike if we edit,
  we don't);  CC BY-ND -> credit + keep text byte-exact (we do). [PD] -> none.
  Store each title's copyright + licenseUrl in the manifest so credit travels.

HOW IT MAPS (offline-first): HelloAO is a BUILD-TIME source. Bake each text into
a standalone SQLite .db.zst on R2 like KJV today; Rust ATTACHes + re-attaches on
boot, so downloads are fully OFFLINE. Ingest: GET the `api:` complete.json -> map
to the standalone schema (mirror data/ingest-xml-translations.ts, canonical 1..66
books) -> verify John 3:16 @ translation_id=1 -> zstd+sha256 -> add slug to
data/build-store-upload.ts allowlist + manifest -> upload.

Legend:  [PD]=public domain   [OK]=CC permissive (license shown)
